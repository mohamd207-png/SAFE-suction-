### 🚀 Live Interactive 3D Demo
Open `index.html` in any modern web browser to interact with the **SAFE-Suction™** bedside unit in 360°:
1. **6 Bench Line States Simulation:** Test real-time pressure and flow waveform responses across Normal, Partial Clog, Complete Blockage, Tissue Contact, Leak, and Undetermined states.
2. **Patient Profile Limits:** Switch between Adult, Pediatric, and Neonatal safety thresholds.
3. **6 Standard Camera Angles:** Instant views for Front, Back, Right, Left, Top, and Bottom.
4. **Engineering Exploded View:** Inspect internal electronics, solenoid valves, and sensors.
