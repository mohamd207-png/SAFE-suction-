### 🚀 Live Interactive 3D Demo
Open `index.html` in any modern web browser (or via GitHub Pages) to interact with the **SAFE-Suction / DynEvac™** bedside unit in 360°:
1. **6 Bench Line States Simulation:** Test real-time pressure (`mmHg`) and flow (`L/min`) waveform responses across:
   - `Normal` (Steady flow, pressure near setpoint)
   - `Partial Clog` (Viscoelastic mucus resistance)
   - `Complete Blockage` (Zero flow, peak vacuum alert)
   - `Tissue Contact` (Sudden flow drop -> Automatic vacuum relief & mucosal protection)
   - `Leak or Disconnect` (High flow, low vacuum alert)
   - `Undetermined` (Fail-safe: *Alerts first | Clinician decides*)
2. **Patient Profile Limits:** Switch between **Adult (`-120 mmHg`)**, **Pediatric (`-100 mmHg`)**, and **Neonatal (`-80 mmHg`)** safety thresholds.
3. **6 Standard Camera Angles:** Instant buttons for Front, Back, Right, Left, Top, and Bottom views.
4. **Engineering Exploded View:** Inspect the internal PCB, dual proportional solenoid pinch valves, and pressure/flow sensor array.
